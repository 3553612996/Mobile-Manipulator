# 模型

模型权重（`.rknn` / `.onnx` / `.pt`）不入库，由 `tools/` 下的脚本重新生成。
每发布一个模型，在下表补一行记录。

| 模型 | 任务 | 训练日期 | 数据集版本 | 输入尺寸 | mAP50 | 量化 | MD5 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | |

## 记录要求

- **数据集版本**：写清采集时间与场景（光照、距离、背景），换场景要重训。
- **mAP50**：训练集验证结果，同时记量化后的板上精度，两者差距 >2 点要查原因。
- **MD5**：`md5sum best.rknn`，用于确认板上跑的是哪个文件。

## 重新生成的流程

```
tools/record_dataset.py  → 采集
tools/label.py           → 标注
tools/train.py           → 训练（记录超参）
tools/convert_onnx2rknn.py → 转换 + 量化
```
