# robot_speech

Vosk 离线语音识别与意图解析：音频 → 文本 → 结构化意图。

## 规划

| 环节 | 说明 |
| --- | --- |
| 音频采集 | 麦克风阵列，按设备名/索引配置，不写死 |
| 识别 | Vosk 中文小模型，流式输出 |
| 意图解析 | 命令词/模板匹配，输出导航点、抓取目标等意图 |
| 输出 | 意图事件交给 `robot_task`，不直接控制底盘或机械臂 |

## 约束

- 完全离线，不依赖云端 ASR；
- 识别模型文件不入库，路径由参数配置；
- 语音失效时由界面/遥控接管，不影响运动与导航。

## 当前状态

M1 只有包骨架。语音节点在 M9 实现；节点名在实现时确定，避免过早冻结。
